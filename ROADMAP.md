# Roadmap

## Near term

- Keep the addon stable as a narrow Jackett -> Stremio bridge.
- Improve heuristic filtering for language and resolution.
- Add configurable keyword rejection for noisy releases.
- Make Docker workflow reliable for local self-hosting.

## Mid term

- Add richer language aliases and release-title matching rules.
- Improve stream labels so accepted filters are visible in Stremio.
- Add sample deployment docs for local LAN and reverse-proxy use.
- Publish the fork under its own remote and image name.

## Later

- Add simple integration tests around filtering behavior.
- Consider optional indexer allowlist/denylist controls.
- Consider optional manifest branding/versioning for the fork.
